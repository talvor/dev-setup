# CLI Tools to Install from URLs (all operating systems)
# Format: name|url|method
# Methods: script, binary, archive
# One tool per line, comments start with #
#
# Only add a tool here if the same URL works on every OS we support.
# OS-specific URLs (or tools only wanted on some OS) go in lists/<os>/urls.txt.
# The OS list is read after this one and only ever adds to it.

## Example entries (uncomment and modify URLs as needed):
# tool-name|https://example.com/install.sh|script
# binary-tool|https://example.com/tool-binary|binary
# archive-tool|https://example.com/tool.tar.gz|archive
